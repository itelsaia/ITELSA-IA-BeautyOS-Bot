## Inicio de una nueva sesión

Usar:

> Trabajamos únicamente en la plantilla maestra de BeautyOS. Lee `AGENTS.md`, `docs/README.md` y `docs/ESTADO-BEAUTYOS.md`. Cada cliente debe tener Sheet, GAS, despliegue, tenant, WhatsApp y agente independientes. No mezcles este proyecto con el CRM comercial de ITELSA IA.
