# Configuración del demo BeautyOS

La guía vigente está en [`docs/PREPARAR-DEMO.md`](docs/PREPARAR-DEMO.md).

## Recursos privados

Los IDs, URLs y datos del demo activo deben guardarse localmente en:

```text
ops/demos/demo-beautyos/FICHA-PRIVADA.md
```

La carpeta `ops/` está ignorada por Git.

## Regla

- El demo se reutiliza y se limpia.
- Solo usa datos ficticios o mínimos.
- Nunca se entrega como instancia productiva.
- Un cliente ganado recibe Sheet, GAS, Web App, tenant, WhatsApp y agente nuevos.
