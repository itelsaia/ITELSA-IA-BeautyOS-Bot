# Estado de despliegue BeautyOS

El estado general del producto está en [`docs/ESTADO-BEAUTYOS.md`](docs/ESTADO-BEAUTYOS.md).

El estado de cada instancia productiva debe registrarse en:

```text
ops/clientes/<clientSlug>/FICHA-PRIVADA.md
```

No versionar:

- IP o usuario del servidor;
- Web App URL;
- IDs de Google;
- nombres de instancias reales;
- teléfonos;
- claves o tokens;
- datos de clientes.

El estado comercial, los cobros y la suscripción permanecen en `CRM-ITELSA-IA`.
